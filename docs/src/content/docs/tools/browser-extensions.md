browser (Chrome / Dia) で使用しているextension。security、development、navigation、customization、productivityの5 category。

## Extension一覧

### Security

| Extension | 説明 |
|-----------|------|
| 1Password | password manager。browser内でのautofillとcredential管理 |

### Development

| Extension | 説明 |
|-----------|------|
| Enhanced GitHub | repo size, file size, download linkの表示 |
| JSON Formatter | JSONのformatとsyntax highlight |
| Material Icons for GitHub | GitHubのfile treeにMaterial Design iconを表示 |
| Refined GitHub | GitHub UIの改善 (200+ features) |

### Navigation

| Extension | 説明 |
|-----------|------|
| Vimium | Vim-styleのkeyboard navigation。`f`でlink hint、`j/k`でscroll |

### Customization

| Extension | 説明 |
|-----------|------|
| Stylus | custom CSSのinjection。GitHubや各サイトの外観を調整 |

### Productivity

| Extension | 説明 |
|-----------|------|
| Text Blaze | text expander。templateとsnippetの展開 |
| Easy Grouping for Google Calendar | calendarのgroup切替 |

## 管理

extension listは`~/.config/browsers/extensions.json`で管理している。ID、名前、category、説明をJSONで記録。
