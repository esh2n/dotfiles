# OmniWM

Niri/Hyprland inspired tiling WM (github.com/BarutSRB/OmniWM).

`settings.toml` is generated by the app on first launch — this directory is
symlinked to `~/.config/omniwm`, so the generated file lands here and gets
tracked once tuned.

## Editing settings.toml — IMPORTANT (verified 2026-08-19)

OmniWM owns this file. External edits are silently discarded unless done
exactly like this:

1. Quit the app gracefully (`osascript -e 'quit app "OmniWM"'` — NOT
   `mado stop`, which kills it and triggers a backup restore on next launch)
2. Edit the file (keep the schema valid — see below)
3. `open -a OmniWM`

"Live-reloads on save" applies to GUI changes only. Edits while running, or
after an unclean kill, or that break decoding (e.g. removing a required
field) are all reverted from an internal backup at launch.

## Applied on top of the target setup (2026-08-19)

- Workspace bar labels: number + emoji via `displayName`
  (`1 💻 / 2 🌐 / 3 💬 / 4 📝 / 5 🎧 / 6 ❤️ / 7 🚀`)
- `moveWorkspaceToMonitor.*` bound to `ctrl-cmd-arrows` (runtime move only —
  resets on restart; permanent placement is Settings > Workspaces)
- Float toggle: `alt-t` (per target setup); column tabbed moved to
  `alt-shift-t` (was upstream default on `alt-t`)
- Scratchpad: `alt-shift-space` toggle, `ctrl-alt-shift-space` assign
- `general.ipcEnabled = true` — `omniwmctl` works

### monitorAssignment facts (from source, WorkspaceConfig.swift)

- Required field — "unassigned/dynamic" does not exist; removing it corrupts
  the file and triggers the backup restore
- Cases: `main`, `secondary` (heuristic, unreliable across monitor setups),
  `specificDisplay` (by display UUID — **falls back to the nearest available
  monitor when disconnected**, so it degrades gracefully away from the desk)
- Preferred: assign real displays via GUI Settings > Workspaces dropdown
  (`specificDisplay`); persists across restarts and locations

## Agreed target setup (2026-08-05) — apply after first launch

Style: "everything always visible" (not workspace-separated). OmniWM is the
auto-layout engine for a fixed desk, replacing manual Loop snapping.

### Monitors

- **Main monitor — Niri, one workspace:**
  `[Cursor/VSCode 0.5][Ghostty 0.25][Dia/Notion 0.25]` — permanent columns
- **Sub monitor — Dwindle (BSP), notification dashboard:**
  Slack / Discord / Slack activity window, all visible in a grid
- Workspaces: `1` = the desk, `2` = overflow only (Spotify etc.)

### Keybinds (match paneru muscle memory)

- Focus: `alt-h/l` (columns), `alt-j/k` (within column)
- Move: `alt-shift-h/j/k/l`
- Fullscreen: `alt-f` (unbind default `alt-Return`)
- Float toggle: `alt-t`
- Column width: `alt-r` / `alt-shift-r`
- Workspaces: `alt-1` / `alt-2`
- Keep defaults: quake `` alt-` ``, palette `ctrl-alt-space`, overview
  `alt-shift-o`, layout toggle `alt-shift-l`
- **`alt-space` stays with Raycast** (Ghostty hide/show toggle — must work
  in every profile, and OmniWM binds die when another WM profile is active,
  so OmniWM must NOT claim this key). Under omniwm the toggle just
  hides/shows the tiled Ghostty column (brief reflow, harmless).
- **`alt-shift-space` = scratchpad, starting with Obsidian** (quick notes
  from any workspace; pairs mentally with alt-space = Ghostty toggle).
  Add a second app (e.g. Spotify) only after this sticks. Never `alt-space`.

### App rules

- Slack, Discord → sub-monitor workspace
- Cursor, VSCode, Ghostty, Dia, Notion → main monitor
- Gather, Finder, System Settings → float (Gather must stay float —
  meeting workflow + hammerspoon z_to_f_spammer)

### Verified against the real schema (2026-08-05)

- Workspace → monitor pinning: `[workspaces.monitorAssignment] type =
  "main"/"secondary"`. Workspace 3 = 💬 comm dashboard (dwindle, secondary).
  NOTE: "secondary" resolved to the Built-in Retina Display on the 3-monitor
  setup — adjust in Settings > Monitors if the external sub monitor is wanted.
- Scratchpad: `alt-shift-space` = toggle, `ctrl-alt-shift-space` = assign
  focused window to scratchpad. To register Obsidian: focus it once and press
  `ctrl-alt-shift-space`.
- Column width presets: `niri.containerPrimarySpanPresets` (1/3, 1/2, 2/3,
  3/4 — paneru parity), cycled with `alt-r` / `alt-shift-r`.
- IPC: `general.ipcEnabled = true` (requires OmniWM restart to take effect);
  `omniwmctl query workspaces` works.
- App Rules in settings.toml carry min sizes only — float指定 and workspace
  auto-assignment are done via GUI Settings > App Rules (schema fields for
  those are not emitted by default; check what the GUI writes).
