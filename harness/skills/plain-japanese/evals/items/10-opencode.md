## 事実

1. 今は加えない。OpenCode 2.x が正式版（既定のインストール）になったら、2.x の API だけを対象に薄いハーネスとして加える。
2. 加えるときの範囲は、規則・skill・エージェント・LiteLLM の接続先・MCP・ガードのプラグイン。
3. ガードは 1.x と 2.x の互換の無い 2 つの API で書く必要がある。
4. プラグインの読み込みに失敗しても、OpenCode はガードなしで動き続ける。
5. OpenCode 自身が、権限の仕組みは境界ではないと文書に書いている。
6. 2.x はほぼ毎日更新され、設定の名前をほぼすべて変えている。
