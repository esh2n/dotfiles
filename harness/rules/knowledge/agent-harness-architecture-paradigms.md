# ルールベースのツールコール・ガードは十分なセキュリティ境界か、専用の判断モデルはどこまで有効か

確認日: 2026-09-22

## 答え

ルールベースのガード（Bash/Write/Edit/MCP の呼び出しを正規表現/glob のポリシーで allow/ask/deny 判定し、fail-closed で運用する方式）は、あらゆる角度からの調査で「OS レベルのサンドボックスの上に乗る、必要な防御の一層」として支持されるが、「それ自体がセキュリティ境界になる」ことは一度も支持されなかった。ポリシー表現・確認・監査の層としては本物の価値があるが、動機のある攻撃者に対する境界にはならない。専用の「判断モデル」（安価な別モデルにルーティング・スキル選択・圧縮の判断だけをやらせる仕組み）は、モデル階層のルーティングに限っては明確に裏付けがある（コストギャップが大きく、判断に必要な情報が軽い）。しかしスキル選択と圧縮については裏付けがなく、条件（大きなコストギャップ、軽い情報だけでの判別可能性）を満たしていない可能性が高く、Anthropic 自身の Claude Code はこの二つをメインモデル自身にやらせている。

## 根拠

- AgentDojo（arXiv:2406.13352）: ツールフィルタリング防御は攻撃成功率を 7.5% まで下げるが 0% にはならず、「必要なツールが攻撃の実行にも十分な場合」に該当するテストケースの 17% で構造的に失敗する。
- Anthropic の Claude Code ドキュメント（`code.claude.com/docs/en/sandbox-environments`, `.../permissions`）: 「分類器はパー・アクションの制御であって隔離境界ではない」「`Bash(command:rm *)` のようなルールは複合コマンドで回避可能なため Claude Code 自身が無視し起動時に警告する」と明記。
- OpenAI の Codex ドキュメント: サンドボックスと承認ポリシーは独立した二層であり、承認を無効化してもサンドボックスの強度は変わらないと明記。
- Google の SAIF ホワイトペーパー: 決定的なポリシーエンジン（ルール層）を「テスト可能・監査可能」だが「未想定の文脈では正当な行動を塞いだり有害な行動を通したりしうる」と評価し、推論ベースの層と並ぶ「二層とも必須、どちらか単独では不十分」という立場を取る。
- 実際に開示された回避事例: Claude Code のコマンド許可リストが `ping`/`nslookup`/`dig` を安全と分類していたため DNS 経由のデータ持ち出しに使われた（CVE-2025-55284）。Anthropic の Filesystem MCP サーバーはパスの `startsWith` 比較のみで許可判定していたため、兄弟ディレクトリに漏れた。
- RouteLLM（arXiv:2406.18665）・Hybrid LLM（arXiv:2404.14618）・FrugalGPT（arXiv:2305.05176）は、モデル階層ルーティングに限って専用の安価な判断層がコストを大きく下げつつ品質を維持できることを実測で示している。
- Anthropic のドキュメント: Claude Code はスキル選択も圧縮も、専用の判断モデルではなくメインモデル自身が行うと明記している（"we implement this by passing the message history to the model to summarize and compress the most critical details"、スキルは system prompt 中の description をメインモデルが読んで選ぶ）。

## 注意点

- 「fail-closed で harness 非依存の一つのポリシーを複数ハーネスに適用する」という設計自体は、調査した範囲のどのベンダーにも前例がない——正しい選択ではあり得るが、業界標準の実装ではなく独自の設計だと認識しておくべき。
- スキル選択・圧縮について「専用判断モデルが main モデル自身に勝る」ことを示す一次資料も、逆に「劣る」ことを示す一次資料も見つからなかった——沈黙は肯定の証拠ではない。
- Google の枠組み（ルール層を「補助」ではなく「対等な必須層」とする）は Anthropic/OpenAI の枠組み（ルール層はサンドボックスに従属する UX 層）と強調点が異なる。どちらも「ルール単独では不十分」という結論では一致している。
- 「圧縮に外部ジャッジを使うと悪い」という直接の失敗事例（null result）は見つからなかった——推論であって実測ではない。
