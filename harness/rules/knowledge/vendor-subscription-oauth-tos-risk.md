# サードパーティのコーディングハーネスはClaude/ChatGPTのサブスクOAuthトークンを使ってよいか、認証失敗時にサイレントフォールバックするか

確認日: 2026-09-23

## 答え

Anthropicは「Claudeサブスクをサードパーティクライアントで使う」ことを一律禁止してはいない——公式のClaude Agent SDK経由であれば、2026年6月時点で専用の課金制度（毎月クレジット）まで用意しようとしていた（ただし6月15日に一旦停止され未確定のまま）。しかしConsumer ToSの文言は解釈の余地を残しており、実際に2026年1月、Claude Code以外のサードパーティクライアント（opencode）でMaxサブスクのOAuthを使っていたユーザーが大量にBANされる事件が起きた。opencode側はAnthropicの法務部門から直接連絡を受け、クローズコメントで「ToSはClaude Code以外でのMax利用を禁止している」と認めている。OpenAI側はさらに曖昧で、サードパーティによるChatGPTサブスク認証利用について公式な可否表明がなく、「動くが契約ではない」状態を求めるissueが複数openのまま放置されている。サイレントフォールバックについては、omp（oh-my-pi）は認証失敗時に警告なしで「利用可能な最初のモデル」へ自動的に切り替える仕様であり、piは「認証失敗時に他プロバイダへ黙って切り替えない」ことを明示の設計方針としているが、拡張プロバイダ登録のレースコンディションに起因する意図しないサイレントフォールバックが実測で10回中4回という頻度でバグ報告されている。

## 根拠

- Anthropicヘルプセンター「Use the Claude Agent SDK with your Claude plan」（直接取得）: 「Claude Agent SDK、`claude -p`、サードパーティアプリの利用は現在もサブスクの利用枠から消費される」「サードパーティアプリがAgent SDK経由でサブスク認証すること」を公式に認知——ただし2026-06-15にこの制度変更は一時停止（pause）されている。
- `github.com/anomalyco/opencode` issue #6930（直接取得）: 「Claude Max 5からMax 20にアップグレードした際にBANされた。Anthropicのエンジニアに確認したところ、OAuthをこの方法で使うことはToS違反だと分かった」。同issueのクローズコメント（opencode開発者本人と見られる投稿）: 「Anthropicの法務チームからこのissueへの対応を要求され、ToSはClaude MaxサブスクをClaude Code以外で使うことを禁止していると認める」。
- `github.com/openai/codex` issue #36886（open、直接取得）: 「ChatGPTサブスク資格情報についてサードパーティクライアント向けの認証契約が文書化されていない」「今のところ動いているのは観察によるものであって契約によるものではない」。
- ompの`docs/models.md`（直接取得）: `findInitialModel`は既定プロバイダの認証が失効すると自動的に「利用可能な最初のモデル」まで5段階でフォールバックする仕様と明記されている（フォールバックが起きたこと自体を警告する記述はない）。同種の「exit 0で警告なく黙って切り替わる」パターンが認証以外のサブシステム（Ollamaモデル選択、`share --gist`）でもissue化されている。
- piのPR #8966（直接取得）: 「認証失敗時にプロバイダを名指ししてエラーを出す。自動フォールバックは導入しない」と設計方針を明記。しかしissue #8810（直接取得）は「10回中4回、意図せず別プロバイダの既定モデルで起動する」という実測比率つきのバグを報告している。

## 注意点

- omp・pi自身がAnthropic/OpenAIから実際にBANを受けたという一次資料は見つからなかった——確認できたBANの実例は別プロジェクト（opencode）に対するものである。
- サブスクOAuthとAPIキー経由ゲートウェイのコスト・レイテンシを定量比較したベンチマークは、四方向のどのレンズにも見つからなかった（定性的な証言のみ）。
- DSH（DeepSeek Harness）固有のフォールバック実装・認証規約は調査対象外だった。
- OpenAI公式のポリシーページ（利用規約・ヘルプセンターの該当記事）はJSチャレンジまたは403のため本文を直接取得できておらず、GitHub issue内で引用された断片のみで判断している。
